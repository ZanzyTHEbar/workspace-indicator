# Embedded font

Lato Medium 2.015, by Łukasz Dziedzic, is embedded unmodified under the
SIL Open Font License 1.1. The complete copyright/license notice is `LICENSE`.
No font file or Fontconfig configuration is required on the user's machine
when using the embedded default.

Reproducible source: Debian's upstream-font package
<https://deb.debian.org/debian/pool/main/f/fonts-lato/fonts-lato_2.015-1_all.deb>,
member `usr/share/fonts/truetype/lato/Lato-Medium.ttf` of `data.tar.xz`.
